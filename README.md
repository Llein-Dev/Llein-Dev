## `05` — Engineering Principles

I generally optimize for:

* **Clear architecture** over unnecessary abstraction
* **Performance** where it affects real workloads
* **Maintainability** over clever code
* **Observable systems** over hidden complexity
* **Practical UX** over feature accumulation
